# Google Maps Lead Generation & Scoring
![Automated B2B Lead Generation](Automated%20B2B%20Lead%20Generation.png)

## Project Overview
A B2B lead-generation automation system developed with n8n that discovers businesses through Google Maps APIs, filters irrelevant results, scores potential leads, and organizes qualified businesses in Google Sheets.

The project demonstrates practical workflow automation, API integration, data processing, and JavaScript programming.

## Key Features
- Automated business discovery by location
- Google Maps API integration
- Multi-page results retrieval (Pagination)
- Business category and location filtering
- Rule-based lead scoring and prioritization
- Google Sheets integration
- API request retry configuration

## Technologies & Skills

**n8n | JavaScript | REST APIs | Google Maps APIs | Google Sheets | JSON | Data Filtering | Workflow Automation**

## Business Value
The system is designed to reduce manual lead research and help sales teams identify and prioritize relevant businesses more efficiently.
